# Publishing Notes

Date: 2026-06-10

## Shop Tag Placeholder

The final-slide shop line intentionally uses a placeholder:

`via le tag boutique IG/TikTok Shop`

Before publishing, connect or verify the live commerce route:

- Instagram Shop / Meta Commerce Manager product tagging.
- TikTok Shop product tagging, if Sonagi decides to use TikTok Shop for the same product.

Do not publish these carousels with the shop-tag wording unless the product can actually be tagged in the post.

## Final Slide Rule

Do not label the final slide "CTA" on the visual. Use a human label such as:

- `À faire`
- `Le geste`
- `La suite`
- `Pour toi`

The final slide should still include:

- Shop placeholder or live shop tag route.
- Quiz link: `sonagibeauty.com/consultation.html`.
- Full article link on Sonagi Reference.

Normal slides should not say "next slide", "dernière slide", or repeat outbound URLs. Use a lighter platform-native footer:

`Sauvegarde ce guide · routine + références dans le profil Sonagi`
